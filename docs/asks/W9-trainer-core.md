## 1. Server (the one allowed change): `GET /api/admin/roster` in `server/admin.js`
`requireUser, requireAdmin`. Returns `{ needsYou: [...], clients: [...] }` for the trainer's clients only:
- `needsYou`: entries `{kind: 'missed'|'unread'|'drafts', user_id?, user_name?, count, detail}` — `missed`: per client with any `workout_assignments` `status='assigned'` and `scheduled_for < CURRENT_DATE` within the last 7 days (count = how many; `detail` = the dates `Mon · Wed`); `unread`: per client with client-sent messages `read_at IS NULL` (count); `drafts`: one entry when pending `ai_drafts` exist for the trainer's clients (count). Ordered: missed, unread, drafts.
- `clients`: `[{id, name, email, last_checkin, readiness_today (score or null), next:{scheduled_for, title}|null, streak (consecutive completed assigned days ending at the last assigned day ≤ today, computed with `server/streaks.js` `sessionStreak` from the client's assignments), program_title (of the next assignment), on_track (true when no missed in 7 days)}]` ordered by name.
Tests in `admin.test.js`: a client with a missed assignment appears under `needsYou` with the right date and `on_track=false`; an unread client message counts; a pending draft counts once; trainer B's roster is empty; streak and next match the fixtures.

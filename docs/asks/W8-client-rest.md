## 2. `src/client/Coach.jsx` (frame 5)
Segmented control `Kyle · History · Offers` (three `Chip`-like buttons, ≥ 44 px, `aria-pressed`; remembered per session in `sessionStorage` `workhart.coachSeg`).
- **Kyle**: the thread from `GET /api/messages` (refetched on open and after a send; `POST /api/messages/read` on open when any Kyle message is unread, then `refetch()` so the tab badge clears). Kyle messages = `Avatar` + a surface2 bubble with a small "Play" `Button ghost` that `speak`s the body (the `Waveform` shows while `talking` on that bubble); client messages = deep-blue bubble right-aligned (`T.color.energyDeep`, white text); timestamps as the board shows (`Kyle · 7:12 AM`, grouped by day with a kicker). Composer pinned above the tab bar: a textarea (auto-grow to 4 lines) + "Send" (`Button`, disabled when empty; 1–2000 chars); send → optimistic append, `POST`, on failure a `Toast` and the draft kept. Empty state: "No messages yet. Kyle will reach out after your first session."
- **History**: `GET /api/history?days=30` on open; a list of sessions newest first: `Card` with the date kicker, `workout_title` (or "Session"), chips `N sets`, `fmtVolume`, `feel` when set; tap → `Sheet` listing exercises with their sets (`set × reps @ weight`, BW for null). Empty state: "Your sessions from the last 30 days will show here."
- **Offers**: `GET /api/offers` on open; each offer = `Card accent` with kicker "From Kyle", title, blurb, price (`$` + cents/100 with two decimals, hide when 0), kind as a `Chip`, `Button quiet` "Ask Kyle about this" → `POST /api/offers/:id/request` → `Toast` "Sent to Kyle" and switch to the Kyle segment (refetch the thread so the request message shows); 409 → `Toast` "You already asked about this one". Empty state: "Nothing on offer right now."

## 3. `src/client/Fuel.jsx`

## Objective
The client's daily loop in the new look: morning check-in, Today (readiness, the assigned session, streak, week strip, Kyle's latest word), Train (one exercise per screen, targets beside the set grid, rest timer), the set-end moment (Kyle's line, written by the server from the sets just logged, spoken through the untouched voice route), and Finish (scorecard, achievement reveal, Kyle's finish line, one feel tap). Everything renders from the server; no constant stands in for data.

## 2. `src/client/` (new)
- `useBootstrap.js`: `useBootstrap(session)` → `{data, loading, error, refetch}`; one `GET /api/bootstrap` on mount; a 401 anywhere calls the `onSignedOut` passed down.
- `useSpeaker.js`: one `createSpeaker` per shell (`useRef`), `{speak, stop, talking, status, line}` as React state; `voiceOn` from `profile.voiceOn !== false`.
- `engine.js` (pure, tested): `sessionFromAssignment(a)` → `{assignmentId, title, programTitle, exercises:[{key, name, info, restSec, rows:[{set_no, reps, weight_lbs, target_reps, target_weight_lbs, done:false}], note}]}`; `targetsHit(rows)` → `{hit, total}` over rows with a target; `volume(rows)` (Σ reps × weight over done rows, 0 for bodyweight); `lastSessionFor(key, workoutLogs)` → `{rows, volume, topWeight}` from the most recent log containing that exercise, or null; `sessionTotals(exercises)` → `{targetsHit, targetsTotal, volume, setsDone}`; `weekStrip(assignments, todayStr)` → 7 entries Mon–Sun `{date, label, state: done|assigned|missed|rest|today}`; `estMinutes(exercises)` → Σ sets × (rest + 45 s) rounded to 5; `todayStr(now)`; `sessionKey(assignmentId)` for sessionStorage.
- `ClientShell.jsx`: holds bootstrap + speaker; `TabBar` items Today · Train · Coach · Fuel · You (icons from lucide-react); `Header` per screen; routes: `today` → `Today`, `train` → `Train`, the other three → `<Workhart session onSignedOut forcedTab="coach"|"fuel"|"you" />` (see §3). When bootstrap shows no check-in for today and the check-in has not been skipped this session (`sessionStorage` `workhart.checkinSkipped.<day>`), the shell shows `Checkin` first.
- `Checkin.jsx`: the board's morning check-in, from `CHECKIN_QS`: one question at a time, four word-first answer cards (≥ 44 px), blue `Bar` progress, ‹ Back, Skip, auto-advance 180 ms, last answer finishes: `POST /api/checkins {day: todayStr, score, answers}` → `refetch()`; `earned` in the response → a `Toast` naming the achievement. Score math exactly as the legacy survey (sum of 0–3 points / 21 × 100, rounded).
- `Today.jsx` (frame 1): `Header` kicker = weekday + date, title "Morning, <first name>" (afternoon/evening by hour); `Ring` with today's score or `null` + a "Check in" `Button` when none; the session card (`Card accent`): kicker "Today from Kyle", title, "N exercises · M sets · ~X min" (+ "· <program_title>" when set), chips `Streak <n>` (good tone when ≥ 3) and the last session's "k of n targets hit", `Button` "Start session" (or "Completed" state with a quiet "Train again") → `onSelect("train")`; no assignment today → a quiet card "No session today" with the next assignment's date and title; Kyle's latest message (`GET /api/messages`, the last `sender: kyle` row) as a `KyleLine size sm` with a play button that `speak`s it; "This week" row + the 7-day strip from `weekStrip` (done = deep blue fill, today = blue outline, missed = warn tint, rest = surface2).
- `Train.jsx` (frames 2 and 3): with no assignment today → the "No session today" card and the next date; with one → `Session`: a `Bar` of exercise progress, kicker "Exercise i of n", display title = exercise name, chips "Target s × r @ w" and "Last <top weight> × <reps>" (from `lastSessionFor`), `SetGrid` with the rows (reps/weight editable, check toggles done; checking a set starts the rest countdown shown under the grid as "Rest 1:30 → 0:42", `+ set` adds a row copying the last), `Button quiet` "Watch the form video" (Sheet with the nocookie embed), `Button` "Done with <exercise>" → `POST /api/coach/line kind exercise` with the done rows → `KyleMoment` (full-screen: `Avatar` 72, `Waveform` while `talking`, the line at 24 px display, chips `k of n hit`, `Volume N lb`, `= last time` / `+N%` / `−N%` vs `lastSessionFor`, `Button` "Next: <exercise>" or "Finish session", `Button quiet` "Say it again"); the text shows at once and `speak(text)` runs when the response lands; a speech failure leaves the text. A `Button ghost` "End session early" (confirm inline) goes to Finish with what is done. The in-progress session is mirrored to `sessionStorage` under `sessionKey` after every change and restored on mount; cleared on Finish.
- `Finish.jsx` (frame 4): on entry `POST /api/workout-logs` (`performed_at` = now ISO, `assignment_id`, `sets` = every done row with `set_no` per exercise, `feel: null`) → store `logId`, `earned`; then `POST /api/coach/line kind finish` → `speak`. Layout in this order: kicker = title, display "Good work, <first name>", `Celebration` for each earned achievement (one at a time; "Next" advances; the achievement's `context.exercise`/`context.program` fills `<exercise>`/`<program>` in the blurb), the two `Numeral` cards (targets hit `k of n`, volume `N k lb` + `+N%`/`−N%` vs the previous log's volume when one exists), `KyleLine size sm` with the finish line + replay, the feel row: three `Chip`s Easy · Right · Hard → `PATCH /api/workout-logs/:id {feel}` and a filled state, then `Button` "Done" → `refetch()` and Today. A failed log POST shows the error in plain words with "Try again" and never loses the rows (they stay in sessionStorage).
